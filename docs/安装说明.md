# 安装 Apple 日历同步到飞书

版本：1.0.1。支持 macOS 14 或更新版本，安装包同时包含 Apple 芯片（arm64）和 Intel（x86_64）代码，无需安装 Xcode 或自行编译。

## 安装应用

1. 从本项目的 GitHub Releases 下载 `Apple-Calendar-to-Feishu-1.0.1-universal.dmg`。
2. 打开 DMG，将“Apple日历同步到飞书.app”拖入 Applications（应用程序）文件夹。更新时请先退出旧版，再替换应用。
3. 也可下载 ZIP，解压后把应用移入“应用程序”。
4. 首次启动时，允许应用读取 Apple 日历。

此版本使用本地临时签名，未经过 Apple Developer ID 签名和公证。macOS 可能阻止首次打开：请先确认下载来自本项目、核对 `SHA256SUMS.txt`，再按系统提示到“系统设置 → 隐私与安全性”选择“仍要打开”。如果组织安全策略不允许，请遵循该策略。

## 配置飞书连接

应用安装后，还需在本机安装并配置飞书官方 CLI。应用不包含 CLI，也不包含开发者的凭据；每位使用者都要连接自己的飞书账号。

1. 按照 [飞书官方 CLI 文档](https://github.com/larksuite/cli) 安装 `lark-cli`。
2. 确保可执行文件位于 `/opt/homebrew/bin/lark-cli`（Apple 芯片常用路径）或 `/usr/local/bin/lark-cli`（Intel 常用路径）。
3. 按官方文档配置自己的飞书应用，完成用户身份授权，并开通日历日程的创建、修改和删除权限。
4. 用 `lark-cli auth status` 检查授权状态；应用通过 `--as user` 操作当前账号的主日历。

只有完成飞书连接后，才能实际同步。界面中的“飞书已连接”是现有版本的固定提示，不能代替授权检查；授权或权限不足时，同步会返回错误。

## 使用及更新

打开应用后，默认日期范围为当天至一个月后。选择来源日历，点击“预览变化”，核对后点击“开始同步”。详见 [使用说明](https://github.com/NEWLY2014/Apple-Calendar-to-Feishu/blob/v1.0.1/docs/使用说明.md)。

同步映射保存在 `~/Library/Application Support/AppleToFeishuManualSync/mappings.json`，更新应用不会删除该文件。不要把个人同步映射或飞书授权信息上传到公共仓库。

本工具单向、手动同步 Apple 日历到飞书，不在后台自动运行。

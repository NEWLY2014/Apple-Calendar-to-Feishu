# Apple 日历同步到飞书

这是一个手动同步工具：按你选择的日期范围，把 Apple 日历中的日程同步到飞书主日历，并占用飞书忙闲。

## 使用方法

1. 打开“Apple日历同步到飞书.app”。
2. 首次使用时，允许应用访问 Apple 日历。
3. 选择开始日期、结束日期和需要同步的 Apple 日历。
4. 点击“预览变化”，检查新增、更新和保持不变的日程。
5. 点击“开始同步”，在确认窗口中核对数量后执行。

## 默认设置

- 日期范围默认为当天至一个月后。
- 同步后的日程状态为“忙碌”。
- 日程默认为私密，同事只能看到忙碌状态。
- 不设置提醒、不邀请参会人、不发送通知、不创建视频会议。
- 全天日程默认不同步，避免占用整天；需要时可手动开启。
- 删除同步默认关闭。开启后，只会删除此前由本工具同步、且在本次所选范围内已经从 Apple 日历移除的日程。

每次同步都需要你手动操作并确认；应用不会在后台自动运行。
